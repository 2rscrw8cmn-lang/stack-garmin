# Local font source

Place the properly licensed source font here as:

`Skomelr Quantum.otf`

The project owner has reviewed and cleared the Skomelr Quantum license for STACK/Garmin use. The raw source font remains intentionally gitignored; only generated Garmin bitmap resources are committed to the repository.

Generate Garmin bitmap font resources with:

`python ../tools/gen_fonts.py`
