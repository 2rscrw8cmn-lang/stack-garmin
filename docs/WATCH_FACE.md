# Watch Face

## Goal

Make the Garmin home screen feel like STACK without turning it into a dense fitness dashboard.

## MVP hierarchy

1. Time
2. STACK identity
3. battery + steps
4. small training tower

## Later

- race countdown
- weekly mileage
- today's scheduled run
- readiness / recovery metric if a supported source is available
- cached STACK plan data

## Power rule

The watch face should remain useful with once-per-minute low-power updates. Seconds and animation are nonessential.
